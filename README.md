# GreenPulse 🌱

## Smart Energy Monitoring & Sustainability Platform

GreenPulse is an AI-powered energy management application that helps users monitor electricity consumption, analyze usage patterns, estimate carbon footprints, and receive personalized recommendations for reducing energy waste and promoting sustainable living.

## Features

* User Authentication & Secure Login
* Real-Time Energy Consumption Tracking
* Interactive Dashboard & Analytics
* AI-Powered Energy Saving Recommendations
* Carbon Footprint Estimation
* Historical Usage Reports & Insights
* Appliance-Wise Energy Monitoring
* Responsive UI (Mobile + Web Friendly)

## Tech Stack

**Frontend:** HTML, CSS, JavaScript

**Backend:** Python, Flask

**Database:** SQLite

**Additional Tools:** REST APIs

**Deployment:** Render

## Installation & Setup

### Clone the repository

```bash
git clone https://github.com/kurakulaharshitha/GreenPulse.git
cd GreenPulse
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Start the application

```bash
python app.py
```
